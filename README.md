### 2k Operating System  Version BETA 1.0

## Introduction

2k OS is my hobby project which i finish the BETA 1.0 in 3 days + learning. 2k OS heavily inspired by TempleOS and MS-DOS

* **Architecture:** x86 32bit
* **Screen Resolution:** 640 by 480, 16 colors.

i did not test it on VMware or VirtualBox yet but QEMU run it perfecty.

The point of making 2k OS because it's fun! And i want to share my cool project to everyone can test it or try to use it.

I'm not the programming expert or Computer nerd, I just love Computer Stuff and I believed that "There are no things you can not learn."
